projects

Veil

view repo →

A privacy-focused, terminal-based encrypted P2P messaging app written in Go. Messages route over Tor onion services end-to-end, so there's no exit relay to trust. Identity and handshake use Ed25519 and X25519, messages are encrypted with XChaCha20-Poly1305, and local identity is protected at rest with Argon2id. Built with Bubble Tea for the TUI, plus a burner mode and a panic wipe for key material.

  • Go
  • Tor
  • Ed25519 / X25519
  • XChaCha20-Poly1305
  • Bubble Tea
  • Argon2id
